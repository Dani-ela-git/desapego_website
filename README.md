# Desapego — Site Institucional

Site institucional desenvolvido como projeto da disciplina de Desenvolvimento Web, com foco em doação e reaproveitamento de itens.

## 🚀 Tecnologias

- JavaScript
- HTML5
- CSS3

## 🎯 O que faz

- Página inicial com apresentação do projeto
- Apresentação dos objetivos e impacto social
- Navegação entre seções

```bash

git clone https://github.com/Dani-ela-git/desapego-website.git

# Abra o arquivo index.html no navegador
# Ou, se preferir, use um servidor local:

# Depois acesse http://localhost:8000
